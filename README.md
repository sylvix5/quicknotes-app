# QuickNotes App

QuickNotes is a lightweight, responsive note-taking web application designed to help users quickly capture, categorize, search, and manage daily thoughts and ideas directly in the browser.

## Features

- **Categorized Notes:** Organize entries into **Personal**, **Work**, or **Study** categories with distinct visual indicators.
- **Form Validation:** Instant error alerts for empty notes or entries exceeding 200 characters.
- **Live Search:** Filter your notes instantly as you type in the search bar.
- **Data Persistence:** Notes are automatically saved to and loaded from `localStorage`.
- **Responsive Layout:** Flexbox-powered layout that adjusts seamlessly to mobile screens using a CSS media query.

## How to Run Locally

1. Clone the repository to your local machine:
   ```bash
   git clone [https://github.com/your-username/quicknotes-app.git](https://github.com/your-username/quicknotes-app.git)
   ```
2. Open the project folder in your code editor(e.g., VS Code)

3. Open index.html directly in your web browser or use a live server extension.
